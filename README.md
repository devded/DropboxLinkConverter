A simple web tool to convert **Dropbox share links** into **direct image links** usable in websites, HTML, or markdown.



## 🚀 Features

- ✅ Paste any Dropbox share URL
- 🔁 Instantly converts it to a direct access link
- 📋 One-click copy to clipboard
- 🎨 Clean, responsive UI with Tailwind CSS
- 💡 No frameworks required — just HTML, TailwindCDN, and plain JavaScript

## 🔗 Example

**Input Dropbox Link:**
```

[https://www.dropbox.com/s/abc123/example-image.jpg?dl=0](https://www.dropbox.com/s/abc123/example-image.jpg?dl=0)

```

**Converted Direct Link:**
```

[https://dl.dropboxusercontent.com/s/abc123/example-image.jpg](https://dl.dropboxusercontent.com/s/abc123/example-image.jpg)

````

You can now use this link in:
```html
<img src="https://dl.dropboxusercontent.com/s/abc123/example-image.jpg" alt="My Image">
````

## 💻 Tech Stack

* HTML5
* Tailwind CSS via CDN
* Vanilla JavaScript
